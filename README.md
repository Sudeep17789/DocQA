
# DocQA — PDF Question Answering Website

A simple web application that allows users to upload PDF documents, ask questions, and find relevant passages from the document.

## Features

- Upload PDF documents
- Extract text directly in the browser
- Search for relevant passages based on questions
- Display page numbers and matching text
- Dark-themed, responsive user interface
- PDF processing happens locally in the browser

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PDF.js

## How to Use

1. Open the DocQA website.
2. Upload a PDF document.
3. Enter a question related to the document.
4. Click **Find answer in PDF**.
5. Review the relevant passages and page numbers.

## Limitations

- This version finds relevant text passages; it does not generate answers using a generative AI model.
- Scanned PDFs may require OCR.
- Text-based PDFs work best.

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Upload a PDF and start searching.

## Deployment

This project can be hosted using GitHub Pages.
